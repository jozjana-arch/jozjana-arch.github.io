Informativa sulla privacy – Pulizia posta Jozjana

Ultimo aggiornamento: 25 novembre 2026

Chi è il responsabile

«Pulizia posta Jozjana» è un'app personale creata e gestita da Jozjana Guga. È un piccolo script Python che gira solo sul suo computer Windows. L'unica persona che lo usa è lei, con il proprio account Gmail (jozjanaga@gmail.com).

Quali dati

Per funzionare, l'app chiede l'accesso al Gmail di Jozjana tramite il permesso Google «gmail.modify». Usa solo mittente, oggetto, etichette, stato letto/non letto e data delle email.

Cosa fa con i dati

Una volta alla settimana l'app:

  • sposta nel cestino di Gmail le vecchie email promozionali, dei social e degli avvisi di lavoro;
  • archivia le vecchie email di aggiornamento già lette;
  • conta le email importanti non lette e mostra un riepilogo sullo schermo del computer.

Cosa NON fa

  • Non invia email.
  • Non salva né trasmette il contenuto dei messaggi fuori dal computer di Jozjana.
  • Non condivide dati con nessuno.
  • Non ha un server, non usa strumenti di analisi (analytics), cookie o pubblicità.
  • Non è usata da altre persone.

Dove sono conservati i dati

Le credenziali e il token di accesso sono salvati solo in locale, sul computer di Jozjana, in una cartella accessibile solo al suo utente Windows. Nessun dato viene conservato altrove.

Come revocare l'accesso

Jozjana può revocare l'accesso dell'app in qualsiasi momento da https://myaccount.google.com/permissions.

Dichiarazione sull'uso dei dati Google

L'uso e il trasferimento a qualsiasi altra app delle informazioni ricevute dalle API di Google da parte di «Pulizia posta Jozjana» rispetteranno la Google API Services User Data Policy, inclusi i requisiti di Uso limitato (Limited Use).

Contatti

Per qualsiasi domanda: jozjanaga@gmail.com

Privacy policy – Pulizia posta Jozjana

Last updated: 25 November 2026

Who is responsible

"Pulizia posta Jozjana" is a personal app created and run by Jozjana Guga. It is a small Python script that runs only on her own Windows computer. The only user is Jozjana herself, on her own Gmail account (jozjanaga@gmail.com).

Which data

To work, the app asks for access to Jozjana's Gmail through the Google permission "gmail.modify". It uses only the sender, subject, labels, read/unread status and date of the emails.

What it does with the data

Once a week the app:

  • moves old promotional, social and job-alert emails to the Gmail trash;
  • archives old, already-read update emails;
  • counts unread important emails and prints a summary on the computer screen.

What it does NOT do

  • It does not send emails.
  • It does not store or transmit message content outside Jozjana's computer.
  • It does not share data with anyone.
  • It has no server and uses no analytics, cookies or ads.
  • It is not used by anyone else.

Where data is kept

Credentials and the access token are stored only locally on Jozjana's computer, in a folder accessible only to her Windows user. No data is kept anywhere else.

How to revoke access

Jozjana can revoke the app's access at any time at https://myaccount.google.com/permissions.

Google data statement

The use and transfer to any other app of information received from Google APIs by "Pulizia posta Jozjana" will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

For any question: jozjanaga@gmail.com
